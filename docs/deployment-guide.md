# 系统部署说明书骨架

## 1. 文档定位
- 用途：作为最终提交包中的部署说明书，说明助教或老师如何在新环境中完成依赖安装、数据库初始化、配置准备、系统启动与基础验证。
- 当前阶段：本文件只锁定结构、信息来源、待补内容和交付边界，仍属于“编码前准备”，不记录任何虚构的安装结果、运行截图或性能数据。
- 最终提交边界：`纳入最终提交包`。

## 2. 主来源与依赖

| 主题 | 主来源 | 本文档的使用方式 |
| --- | --- | --- |
| 系统范围与部署目标 | `docs/superpowers/specs/2026-06-26-mental-health-system-design.md` | 作为部署对象与三端范围依据 |
| Python 依赖 | `requirements.txt` | 最终回填安装命令与版本说明 |
| 应用启动入口 | `run.py`、`app/__init__.py` | 最终回填启动方式 |
| 数据库结构 | `sql/schema.sql` | 最终回填建库与建表步骤 |
| 初始化数据 | `sql/seed.sql` | 最终回填演示数据导入步骤 |
| 配置项 | 代码中的配置文件与最终环境变量约定 | 最终回填配置说明 |
| 验证口径 | `docs/test-report.md` | 对齐“部署完成后最小可运行验证” |

## 3. 最终成稿应包含的结构

### 3.1 环境要求
- 操作系统建议。
- Python 版本。
- MySQL 版本。
- 浏览器要求。
- 网络或本地运行前提。

### 3.2 目录准备
- 提交包目录结构。
- 首次解压后的关键文件位置。
- 哪些文件必须保留，哪些属于可选材料。

### 3.3 依赖安装
- Python 虚拟环境创建命令。
- `requirements.txt` 安装命令。
- 如存在前端静态依赖，需说明是否需要额外安装。

### 3.4 数据库初始化
- 创建数据库实例。
- 导入 `sql/schema.sql`。
- 导入 `sql/seed.sql`。
- 导入顺序与常见失败点。

### 3.5 配置说明
- 环境变量或配置文件清单。
- 数据库连接项。
- 调试模式开关。
- 本地演示账号来源说明。

### 3.6 启动步骤
- Web 应用启动命令。
- 首次启动后的访问地址。
- 学生端、后台端、大屏端入口路径。

### 3.7 部署后最小验证
- 首页可访问。
- 学生端注册/登录页可打开。
- 后台登录页可打开。
- 大屏页可打开。
- 数据库连接正常。

### 3.8 常见问题
- 依赖安装失败。
- MySQL 连接失败。
- 初始化脚本执行顺序错误。
- 端口占用。
