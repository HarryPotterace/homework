## 4. 最终成稿应包含的结构

### 4.1 数据库总体说明
- 数据库名称。
- 使用的数据库产品与版本。
- 字符集与排序规则。
- 业务边界与脱敏原则。

### 4.2 数据表清单
- 每张表的业务用途。
- 与系统模块的对应关系。
- 是否直接面向用户数据、后台数据或聚合数据。

### 4.3 字段说明
- 字段名。
- 类型。
- 是否允许为空。
- 默认值。
- 主键 / 外键 / 唯一约束。
- 字段业务含义。

### 4.4 表关系说明
- 一对多关系。
- 一对一或唯一时段约束。
- 删除和更新策略。
- 预约、测评、树洞、行为日志之间的关联方式。

### 4.5 约束与索引
- 学号唯一。
- 后台用户名唯一。
- 预约时段可用性约束。
- 查询热点字段的索引策略。

### 4.6 ER 图与附图
- ER 图文件名。
- ER 图生成方式。
- 在课程报告中的插入位置。
