# 课程报告正文提纲

## 1. 格式要求
- 封面按老师模板填写。
- 正文汉字使用宋体 5 号。
- 英文使用 Times New Roman。
- 正文行距为 1.5 倍行距。
- 标题格式按老师模板执行。
- A4 纵向排版。
- 标题层级示例：`一概述`、`1.1 标题2`、`1.1.1 标题3`、`1）标题4`。
- 报告内容必须与最终代码实现一致，不能写入未实现功能。

## 2. 章节结构

### 第一章 系统需求分析
- 1.1 系统需求
  - 研究背景与意义。
  - 高校心理健康管理现状与痛点。
- 1.2 功能需求
  - 三端用户场景与功能边界。
- 1.3 性能需求
  - 响应速度、兼容性、可用性与脱敏要求。

建议写法：
- 说明传统问卷式心理排查滞后、掩饰性强的问题。
- 说明本项目为什么要同时做学生端、后台端和大屏端。
- 功能需求部分直接对应注册登录、测评、树洞、情绪感知、预约、响应式、大屏脱敏展示。

### 第二章 可行性分析
- 2.1 技术可行性
  - Flask 单体方案与其它方案对比。
- 2.2 操作可行性
  - 学生端、后台端、大屏端的使用门槛与维护成本。
- 2.3 可行性分析结论

建议写法：
- 技术可行性重点写 `Flask + Jinja2 + MySQL` 方案实现快、部署简单、适合作业交付。
- 操作可行性重点写学生端流程短、后台使用直观、大屏便于值班展示。

### 第三章 概要设计
- 3.1 系统设计原则
  - 亲和、低打扰、去标签化、脱敏展示。
- 3.2 系统设计目标
- 3.3 系统总体架构
- 3.4 设计流程图
- 补充：类谱系树及其说明

建议写法：
- 总体架构可写表现层、控制层、业务层、数据层。
- 设计流程图建议覆盖：注册/登录 -> 测评/树洞/情绪感知 -> 预约 -> 后台查看 -> 大屏汇总。
- 类谱系树重点围绕主要模型或模块关系组织。

### 第四章 系统详细设计与实现
- 4.1 功能模块设计与实现
- 4.1.1 用户注册模块
- 4.1.2 用户登录模块
- 4.1.3 心理测评功能模块
- 4.1.4 情绪感知与自适应交互模块
  - 必写：行为规则、关键词规则、界面自适应策略。
- 4.1.5 心理咨询预约功能模块
- 4.1.6 移动端响应式适配模块
- 4.1.x 方法与创新点
  - 说明本系统如何把人机交互理论、情绪感知规则和三端适配组合成可落地方案。
- 4.2 数据库设计与实现
- 4.2.1 系统 E-R 模型
- 4.2.2 数据库设计
- 4.3 系统开发环境
- 4.3.1 硬件环境
- 4.3.2 软件环境

建议写法：
- 注册模块写前端非空校验、密码强度校验、后端学号唯一性校验。
- 登录模块写 Session 登录态管理。
- 测评模块写 `PHQ-9`、`GAD-7` 展示、得分区间和建议生成。
- 情绪感知模块写 `mousemove`、`click`、`keydown` 三类行为采集，以及关键词规则。
- 预约模块写异步排班接口、创建、取消、后台状态处理。
- 响应式适配模块写手机端触控尺寸、后台桌面布局和大屏聚合展示。

### 第五章 系统测试
- 5.1 系统测试
- 5.1.1 测试任务
- 5.1.2 测试目标
- 5.1.3 测试方案
- 5.2 测试结果及分析
- 5.2.1 系统功能测试
- 5.2.2 系统性能测试
- 5.2.3 兼容性测试
- 5.2.4 结果分析与评价

建议写法：
- 功能测试可引用 `docs/test-report.md` 的功能测试表。
- 性能测试至少记录首页、测评页、大屏页。
- 兼容性测试至少写手机端、PC 后台、大屏三类终端。
- 结果分析要写系统已经满足的要求和目前仍有的局限。

### 第六章 总结与展望
- 心得体会要求真实，不浮夸。
- 回顾设计取舍、系统不足与可扩展方向。

建议写法：
- 总结三端一体、规则式情绪感知、脱敏展示的实现价值。
- 展望可写语音识别、摄像头情绪识别、消息通知等未来扩展，但必须明确本次未实现。

### 参考文献
- 需补充课程相关理论、人机交互设计原则、量表来源、情绪规则依据等文献。

建议至少覆盖：
- 人机交互设计与可用性相关文献
- `PHQ-9`、`GAD-7` 量表来源
- 文本情绪分析或情绪计算相关文献
- 高校心理健康服务场景相关资料

可直接作为初稿检索方向：
- Norman, D. A.《设计心理学》或相关可用性设计文献。
- Kroenke, K. 等关于 `PHQ-9` 的原始论文。
- Spitzer, R. L. 等关于 `GAD-7` 的原始论文。
- Picard, R. W. 关于 Affective Computing 的基础文献。
- 国内高校心理健康教育与危机干预相关研究综述。
