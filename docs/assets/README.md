# 报告素材目录说明

## 1. 文档定位
- 用途：管理课程报告和答辩可能用到的截图、图表、流程图、ER 图、类谱系树、测试表格等素材。
- 当前阶段：本文件只锁定素材清单、命名建议、来源页面和使用位置，不虚构任何“已完成截图”。
- 最终提交边界：`docs/assets/` 目录本身可作为最终提交包的配套素材目录，`README.md` 纳入最终提交包。

## 2. 主来源与依赖

| 素材类别 | 主来源 | 使用位置 |
| --- | --- | --- |
| 页面截图 | 系统真实运行页面 | 课程报告第 4 章、第 5 章 |

| 测试表格与截图 | 真实测试执行结果 | 课程报告第 5 章 |

## 3. 建议目录与命名规则
- 推荐子目录：
  - `screens/`：页面截图
  - `diagrams/`：流程图、架构图、ER 图、类谱系树
  - `tests/`：测试截图、测试表格
- 推荐文件命名：`模块名-用途-序号.ext`
- 例如：
  - `student-home-01.png`
  - `assessment-result-01.png`
  - `system-flow-01.png`
  - `er-diagram-01.png`
- 命名原则：
  - 同一类素材统一英文或拼音，不混用随意缩写。
  - 名称要能看出来源页面和用途。
  - 最终提交包根目录仍需遵守 `班级-姓名-学号` 命名规则，本目录内素材命名不替代总目录命名要求。

## 5. 使用规则
- 所有素材必须来自真实页面、真实测试或真实设计图，不得用占位图冒充结果。
- 每张图在课程报告中都要有图号、图题和引用位置。
- 一张图如果同时服务多个章节，仍要在这里登记主用途，避免重复采集。
- 涉及大屏与后台的截图必须注意脱敏，不能暴露真实学号、联系方式等个人信息。

- 本文件负责“素材清单和素材管理”。
- 流程图画法和图中业务含义由设计说明主讲。
- ER 图数据定义由数据库说明主讲。

- 报告如何插入这些素材由课程报告提纲主讲。
