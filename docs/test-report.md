# 系统测试记录

## 1. 文档用途
- 记录功能测试、性能测试、兼容性测试及结果分析。

## 2. 必含内容
- 测试任务。
- 测试目标。
- 测试方案。
- 功能测试结果。
- 性能测试结果。
- 兼容性测试结果。

## 3. 建议量化口径
- 功能测试：以 `python -m pytest -q` 作为代码级回归基线，并补充人工流程测试表。
- 性能测试：
  - 首页首次加载时间。
  - 测评页提交到结果展示耗时。
  - 大屏看板首屏渲染时间。
- 兼容性测试：
  - 手机端：Chrome Android 或等效移动浏览器宽度。
  - PC 端：Chrome / Edge。
  - 大屏端：1920x1080 全屏投放可读性。
- 脱敏检查：
  - 树洞页不显示姓名、学号。
  - 大屏只展示聚合统计，不展示身份字段。
